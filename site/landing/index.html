03Decisions that shaped it

Medallion, dbt-native

Three zones map one-to-one onto staging → intermediate → marts, each in its own BigQuery dataset. Raw is append-only and every transform rebuilds from it, so a rule change applies retroactively with zero migrations.

ADR-0010ADR-0014

One SQL codebase, two warehouses

Every model runs on DuckDB for development and CI — with no secrets — and on BigQuery in production. Dialect differences live in adapter.dispatch macros, including the prod-only type traps that naive cross-database macros hide.

ADR-0002

Lifecycle, not snapshots

The source APIs have no date filters, so novelty is derived, never requested: first_seen_at, last_seen_at and is_active come from the append-only landing, and a staleness rule ages out a dropped board instead of leaving zombie postings.

ADR-0016ADR-0008

Rules are data

Locations, technologies and titles are dbt seeds, word-boundary matched and regex-safe (C++ and .NET work). Only location removes a row; everything else ranks, so recall stays high until a model can judge fit.

ADR-0015ADR-0023ADR-0028

Security is structural

No secret value exists anywhere in the repo. BigQuery auth is Workload Identity Federation, so there is no key file to leak; workflows are split by permission scope, actions are SHA-pinned, and gitleaks backstops every commit.

ADR-0007ADR-0011

AI that orders, never filters

LLM extraction and scoring run as incremental dbt models against BigQuery's in-SQL AI functions, keyed on a content hash so each text is billed once. The score sorts delivery and can never drop a posting: if it fails, the V1 result still ships.

ADR-0004ADR-0020ADR-0024

04Built to fail loudly

A scheduled pipeline's worst failures produce no signal at all. An invalid workflow file never starts, so nothing emails. A suspended schedule is silent. A run that lands almost nothing still exits zero. Each of these has its own gate here: workflow linting, a dead-man's switch, volume warnings and a source-freshness check.

05Even the prose is tested

Docs drift silently: a file is renamed and the sentence pointing at it still reads fine. A checker in CI verifies every path, make target, model name, heading anchor and ADR number the docs mention, and lets a sentence assert a count against the code — so a number cannot rot under an edit.

06Honest about what is unproven

Two rankings run side by side — an LLM fit score and embedding similarity — because choosing between them without measuring is how a project ends up carrying both forever. Neither is trusted until precision@k over human labels says which one wins, and labels from an LLM cannot settle it: grading a scorer against its predecessor rewards repeating the predecessor's mistakes.
